#  Enterprise Phishing Simulation and Tracking Platform

## Objective

To simulate phishing attacks, monitor employee interaction, measure employee awareness levels, track user actions, and generate analytical reports for improving organizational security awareness.

## Actors

### Admin

* Login securely
* Add and manage employees
* Create phishing campaigns
* Send phishing simulation emails
* View reports and analytics dashboard

### Employee

* Receive phishing simulation emails
* Open email links
* Interact with awareness pages

## Core Modules

### Authentication Module

* Admin registration
* Admin login
* Password encryption
* JWT authentication

### Employee Management Module

* Add employees
* View employee details
* Delete employees
* Group employees by department

### Campaign Module

* Create phishing campaigns
* Send emails to employees
* Store campaign details

### Tracking Module

* Generate unique tracking links
* Track email clicks
* Store timestamps and IP addresses

### Analytics Module

* Total campaigns sent
* Click rate analysis
* Department-wise risk analysis
* Employee activity reports

### Deployment Support

* Internet deployment support
* Intranet deployment support
